# PBB16 C ABI v1

本文定义 `compiler/` 从第 7 阶段起使用的函数调用约定。它是软件 ABI，硬件只强制
`PUSH` / `POP` / `CALL` / `RET` 使用 R6。普通汇编程序可以采用别的内部约定；与 C
目标文件互调时必须遵守本文。

## 数据模型

- 字节为 8 位，`int` 和普通近指针为 16 位、小端，栈槽为 2 字节。
- 栈由 R6 指向，向低地址增长，所有调用边界保持 2 字节对齐，无 red zone。
- 当前 C 子集只传递和返回 `int`。`char`、结构体、变参、32 位值与远指针尚未纳入 ABI。
- banking 不进入普通 C 指针模型；C 地址仍是 16 位逻辑地址。

## 寄存器

| 寄存器 | 用途 | 调用约定 |
|---|---|---|
| R0 | 表达式结果、函数返回值 | 易失 |
| R1 | 第二操作数、地址临时值 | 易失 |
| R2 | 编译器临时值 | 易失；生成的调用序列按需保存 |
| R3 | 第二临时值、未来的函数指针 | 易失 |
| R4 | 大立即数与未来的远调用跳板 | 易失 |
| R5 | 参数基址（ABP） | 被调用者必须保持 |
| R6 | 栈指针（SP） | 返回后必须恢复到调用协议规定的位置 |
| R7 | 局部变量帧基址（FP/LOCALS） | 易失；生成的调用序列保存并恢复 |

Z/S/C/V 均为易失标志。中断/异常入口的保存规则独立于函数 ABI。

## 参数与返回值

参数按源码顺序从左到右求值，每个参数作为一个 2 字节槽压栈；返回值放在 R0。
调用者清理参数，被调用者只清理自己的局部变量。调用 `f(a, b)` 时，生成的调用者序列为：

```asm
PUSH R2
PUSH R5
PUSH R7
MOV  R2, R6          ; 保存参数区上沿
; 求值 a
PUSH R0
; 求值 b
PUSH R0
MOV  R5, R2          ; 建立本次调用的参数基址
CALL FUNCTION_f
MOV  R6, R5          ; 一次丢弃全部参数
POP  R7
POP  R5
POP  R2
```

零参数调用省略返回后的 `MOV R6, R5`，因为 RET 弹出返回地址后 R6 已等于 R5。
R5 必须在被调用函数返回时保持不变，否则调用者无法定位参数区和保存的寄存器。

## 栈帧

设调用协议开始前的栈指针为 S，两个参数的布局如下：

```text
高地址
S-2   调用者 R2
S-4   调用者 R5
S-6   调用者 R7       <- R5（本次参数基址）
S-8   参数 0           = [R5-2]
S-10  参数 1           = [R5-4]
S-12  返回地址          <- 被调用函数入口时的 R6
S-14  局部变量 0        = [R7-2]
S-16  局部变量 1        = [R7-4]
低地址
```

有局部变量的函数建立 R7 帧；无局部变量的函数可以省略这两段：

```asm
MOV  R7, R6
ADDI R6, -local_bytes
; 函数体
MOV  R6, R7
RET
```

第 k 个参数位于 `R5 - 2(k+1)`，第 k 个局部 `int` 位于 `R7 - 2(k+1)`。
大于访存 Imm5 范围的偏移先用 `MOV` + `ADDI` 算出地址，再以偏移 0 访存。

## 符号、范围与兼容边界

- C 函数符号使用 `FUNCTION_<name>`，`_start` 调用 `FUNCTION_main`。
- 第 7 阶段要求函数在调用点之前定义；函数可以直接递归，尚不接受原型或前向调用。
- 硬件 `CALL` 是 PC 相对 11 位，范围为 -1024..+1023 字节。当前汇编器对越界调用
  明确报错；未来的绝对远调用序列使用易失的 R4，不改变参数和栈帧 ABI。
- `main` 必须是 `int main(void)` 或 `int main()`，由 `_start` 调用，返回后在 0x0006 停机。
- ABI v1 不承诺与未来的结构体传值、变参、32 位整数或函数指针扩展二进制兼容；这些
  能力加入前必须先修订本文并增加跨模块测试。
